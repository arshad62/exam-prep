# Assets

Diagrams, screenshots, and figures referenced from the notes.

Reference them from Markdown with a relative path:

```md
![Binary tree rotation](assets/binary-tree-rotation.png)
```

Allowed formats: `png`, `jpg`, `jpeg`, `gif`, `svg`, `webp`. Anything else is
rejected by the pre-commit hook and the CI check. Prefer `svg` for diagrams
(sharp at any zoom, diffs as text) and `png` for screenshots.
